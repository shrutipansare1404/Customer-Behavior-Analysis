# 🛍️ Retail Customer Behavior & Shopping Trends Analysis

An end-to-end Data Analytics project using **Python, SQL, and Power BI** to analyze retail customer purchasing behavior, identify shopping trends, and generate actionable business insights.

## 📌 1. Project Overview

The objective of this project is to analyze retail customer data and understand customer purchasing patterns, product preferences, and shopping behavior.

This project follows a complete data analytics workflow, starting with raw data loading and cleaning in Python, performing Exploratory Data Analysis (EDA), analyzing business problems using SQL, and developing an interactive Power BI dashboard.

The insights help businesses understand their customers, improve sales strategies, and make data-driven decisions.

## 📂 2. Dataset

**Dataset Name:** Retail Customer Behavior and Shopping Trends

The dataset contains customer shopping information, including:

- Customer ID
- Age
- Gender
- Item Purchased
- Product Category
- Purchase Amount (USD)
- Location
- Season
- Review Rating
- Subscription Status
- Payment Method
- Shipping Type
- Discount Applied
- Promo Code Used
- Previous Purchases
- Frequency of Purchases

**Dataset Source:** [GitHub Repository](https://github.com/amlanmohanty1/cust)

## ▶️ 7. How to Run This Project

### Prerequisites

Install the following tools:

- Python
- Jupyter Notebook
- PostgreSQL and pgAdmin
- Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/amlanmohanty1/cust.git
```

### Step 2: Navigate to the Project Folder

```bash
cd cust
```

### Step 3: Install Python Libraries

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### Step 4: Run Python Notebook

```bash
jupyter notebook
```

Open the project notebook and execute the cells.

### Step 5: Run SQL Queries

- Create a PostgreSQL database.
- Import the cleaned dataset.
- Open the SQL script in pgAdmin.
- Execute the queries to perform business analysis.

### Step 6: Open Power BI Dashboard

- Open the `.pbix` file in Power BI Desktop.
- Refresh the dataset if required.
- Explore the dashboard using interactive filters.
